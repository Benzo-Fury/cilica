# AppRecording

The main window while a meeting records: glass sidebar and assistant over the desktop, the note on an opaque inset sheet, the neutral recording control ("Recording · 12:04" with Pause and Stop) in the note's title band and an AI edit waiting for review in the assistant.

Use it as the reference layout for the Tauri main window: 248px sidebar, inset canvas (8px top and bottom on macOS), 380px assistant, 52px title band.
