# Skeleton

Skeletons hold the shape of content while it loads; shimmer text marks AI work in progress.

Skeleton bars match the real layout (title bar 22px, text lines 12px with the last one shorter) and sweep a soft highlight every 1.4s. Use them for note lists and the first paint of a note, never for content under 200ms.

For AI work use `nt-shimmer` text that says what is happening and how big it is ("Summarising 42 minutes of transcript…"). Never a bare spinner.
