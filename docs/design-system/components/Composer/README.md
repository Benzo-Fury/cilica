# Composer

The composer is the assistant's input box.

**Anatomy**: a multiline field (grows to 8 lines), a row with attach (+), the context chip ("This note", a category, or "All notes") and the round Send button (`accent`).

**Working**: a short light travels around the composer edge (conic gradient, 2.4s per lap) and Send becomes Stop (`ink` fill, square glyph). Esc also stops.

↩ sends, ⇧↩ adds a line, ⌘J focuses the composer from anywhere.
