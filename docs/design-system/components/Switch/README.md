# Switch

Switches turn a setting on or off immediately; there is no Save button behind them.

**Consumer provides**: `role="switch"`, `aria-checked`, a label to its left that states the "on" behaviour ("Detect meetings automatically").

**Motion**: the knob travels with `--spring-bouncy` and stretches 5px while pressed (the Apple squish); the track colour fades to `accent` in `--dur-base`.

Use a Checkbox instead when the choice is part of a form or list that is committed later.
