# References

## Not borrowed

- **Claude's terracotta mark and coloured accents.** Cilica keeps one graphite accent.
- **Emoji in note headings** (Apple Notes, Notion). Cilica's copy has none.
- **Otter's full-width blue record FAB and green highlighted transcript rows.** They are too loud for a calm reading surface.
- **A tab bar.** Every reference AI app (Claude, ChatGPT, Granola) uses a drawer or a single stack. Tabs would make Notes, Meetings and Cilica feel like three apps.
