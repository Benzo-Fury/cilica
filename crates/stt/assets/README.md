# Assets

- `sample_speech.wav`: 11 s of John F. Kennedy's inaugural address (20 January 1961), 16 kHz mono
  16-bit PCM. A US government recording, in the public domain. Taken from whisper.cpp's
  `samples/jfk.wav` (https://github.com/ggml-org/whisper.cpp). Settings › Transcription streams it
  to the chosen engine to check that it works (`src/sample.rs`).
