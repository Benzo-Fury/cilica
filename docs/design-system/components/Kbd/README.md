# Kbd

Kbd shows a keyboard shortcut as small keycaps.

Render one `nt-kbd` per key inside `nt-kbd-group`. Use the platform's glyphs: ⌘ ⇧ ⌥ ⌃ on macOS; `Ctrl`, `Shift`, `Alt` spelled out on Windows and Linux (resolve from the keybind registry, never hard-code).

Show shortcuts in tooltips, menus, the palette footer, dialog buttons and empty states. Keep them `ink-3`: they are hints, not content.
