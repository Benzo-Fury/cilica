# Chip

Chips are small pills for metadata and status.

- Neutral (`fill-press`, `ink-2`): date, duration, people, model name.
- `nt-chip-accent`: category and the selected context in the composer.
- `nt-chip-rec`: Recording (with a 6px breathing dot).
- `nt-chip-success`, `nt-chip-warning`: status, always with an icon.

Interactive chips are `<button>`s and darken one step on hover. Never put more than one icon in a chip.
